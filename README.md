# HomeLab
В связи с тем что я обновил пк, мне в голову пришла идея - "А почему бы не использовать старые запчасти и сделать собственный домашний сервер?"
Предисловие: я таким занимаюсь впервые так что много вопросов буду уточнять у нейронок.

Характеристики сервера:
  1) Процессор: r5 3600
  2) Видеокарта: 1050 TI
  3) ОЗУ: 16Gb DDR4 3200
  4) Материнская плата: B450M DS3H
  5) Накопитель: SATA SSD 512Gb

Планы на этот проект:
  1) Понять как работает Docker
  2) Поднять с помощью докера сервер для любой своей игры
  3) Поставить LLM и посмотреть что могут делать локальные нейронки
  4) Поставить заготовки под умный дом
  5) Поставить медиасервер

Первым делом нужно было выбрать ОС. Мой звгляд пал на дебиан по этим причинам:
  1) Долгая тестировка пакетов = меньше шанс, что все отвалится
  2) Минималистичность = серверу незачем тратить ресурсы на граф оболочку и прочее

После установки дебиана на второй пк, поставил статический ip адресс, установил и настроил SSH вход по ключу для простого подключения. Так же на arch сделал алиас "sshconnect" для подключения.
Далее я начал изучать что такое Docker и DockerCompose. Как я пока что понял это просто изолированная среда для запуска всяких приложений. Избавляет от проблемы "на одном устройстве работает, а на другом нет"

Подключил репозитории Docker следующими коммандами:
```
curl -fsSL https://download.docker.com/linux/debian/gpg \
  | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/debian \
  $(. /etc/os-release && echo "$VERSION_CODENAME") stable" \
  | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
```
Были проблемы с ipv6 решилось это принудительной настройкой всей системы по ipv4.

Первым делом на сервере я настроил Jellyfin. Скачал образ контейнера, запустил его, открыл веб-интерфейс по адресу 192.168.1.50:8096, прошёл первоначальную настройку и создал двух пользователей: администратора и зрителя.

Интересно, что видео не загружались только в двух браузерах — Яндекс Браузере и LibreWolf. С LibreWolf всё более-менее понятно, но почему с этим не справился отечественный браузер — пока не разобрался.

После этого загрузил сезон «Волчицы и пряностей» и теперь наслаждаюсь просмотром. Jellyfin доступен с любого устройства внутри локальной сети. В чём преимущества и недостатки такого подхода — ещё предстоит выяснить.
